# 风险信号、停止与转介（risk-boundaries）

> 强制前置：应用任何公式前，先过本清单。出现最高优先级信号 → 立即停止引导，转专业支持。
> 出处：听心格爱 · 东方心理学 · 罗伟泽

## 一、最高优先级（出现即停，转专业支持）

| 信号 | 用户可能怎么说 | 处置 |
|---|---|---|
| 自杀意念/计划 | 「不想活了」「活着没意思」「想结束」「我有具体办法」 | 停引导 → 表达关心 → 建议立即求助 |
| 自伤行为 | 「我伤害自己」「割腕/撞墙」「停不下来打自己」 | 同上 |
| 伤人/暴力 | 「想杀了他」「要报复」「已经动手」 | 停引导 → 保护受害者优先 → 建议求助 |
| 儿童安全 | 涉及未成年人受虐、被伤害 | 儿童保护优先 → 建议求助 |
| 幻听/妄想 | 「有个声音命令我」「有人要害我」 | 停引导 → 建议精神科就诊 |
| 急性失控 | 严重躁狂、意识混乱、无法正常对话 | 停引导 → 建议立即就医 |

## 二、次级信号（不停止，但需转介专业评估）

| 信号 | 处置 |
|---|---|
| 持续两周以上严重抑郁、影响正常功能 | 建议专业评估，明确「不替代治疗」 |
| 酒精/药物/严重行为成瘾 | 建议专业成瘾支持 |
| 持续失眠 + 崩溃 + 躯体症状 | 建议医学检查 |

## 三、处置话术（出现高风险时的固定回应）

AI 必须做到五点：
1. **停止**：立即停止任何「分析/引导/角度切换」。
2. **关心**：「你现在一定很痛苦，能说出来已经很不容易了。」
3. **明确建议**：「这些情况需要专业帮助，请尽快联系专业医生或心理援助。」
4. **给渠道**：提供求助渠道（当地心理援助热线、医院、信任的家人）。
5. **不评判、不敷衍、不转移话题**。

**绝不允许**：在高风险信号下继续套用公式「看见」「引导」，或说「你想开点」。

## 四、现实伤害优先于心理分析

- 若涉及霸凌、暴力、胁迫、职权压迫、现实伤害：先处理现实安全和求助，**不得把加害行为重新解释成「保护」**。
- 任何人都不因「系统分析」而被要求体谅、原谅、继续接触或让步。

## 五、铁律

**安全永远高于「引导」。** 宁可错停十次，不可漏判一次。
