## 核心心法

**神灯满足的是「心」的愿望**——不管是梳理关系、做获客、分析问题，还是撰写触达人心的文案，本质都是看见那颗「心」真正想要什么，然后满足它。

一套方法，解决三类问题：看见自己（情绪、焦虑、内耗）、看见他人（亲子、婚姻、职场）、看见用户（文案、产品、品牌、获客）。

看见行为背后的心（需求、动机、保护、渴望），治根不治表。

## 五层觉察

身体感受 → 情绪命名 → 自动念头 → 深层需求 → 互动模式。

## 三步操作

1. 不贴标签（不说「懒、不听话、脾气差」），改问：这个行为在保护什么、要什么？
2. 五层觉察，看见行为背后的心。
3. 给一个「当下就能做」的最小行动。
