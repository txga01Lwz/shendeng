## 何时用这个技能

- 用户想解决心理困扰：焦虑、内耗、拖延、发火、亲子、婚姻、职场、自我成长
- 用户想理解自己/他人行为背后的需求与动机
- 用户想做用户研究、营销文案、产品、品牌洞察
- **不适用**：心理疾病治疗、生理问题、自伤/伤人/急性危机（转专业支持）

| 继续上次 | 「这是我上次保存的摘要……。请先确认哪些信息仍然有效，再继续；不要把未验证假设当成事实。」 |

## 怎样纠正 AI（用户控制语句）

- 「先停在倾听，不给建议。」
- 「只问我一个问题。」
- 「请把事实和你的猜测分开。」
- 「这个假设不对，请撤回。」
- 「先不要用公式。」
- 「我们换成行动建议 / 方法解释 / 用户研究模式。」
- 「结束这里，不生成续谈摘要。」

## 三个可复制的提示模板

1. **个人困扰**（要倾听）：「读这个链接里的方法，帮我梳理一下：我最近总是控制不住发火。先别急着给方案，帮我看看。」
2. **关系 / 亲子**（要分析）：「读这个链接里的方法，帮我分析：孩子最近不愿上学，可能是什么原因？别贴标签，原因先当假设。」
3. **用户研究 / 文案**（要洞察）：「读这个链接里的方法，帮我做用户洞察：我们的产品用户说『太贵』，可能有哪些真实原因？怎么验证？」

## 核心心法

看见行为背后的心（需求、动机、保护、渴望），治根不治表。

## 五层觉察

身体感受 → 情绪命名 → 自动念头 → 深层需求 → 互动模式。

## 三步操作

1. 不贴标签（不说「懒、不听话、脾气差」），改问：这个行为在保护什么、要什么？
2. 五层觉察，看见行为背后的心。
3. 给一个「当下就能做」的最小行动。
